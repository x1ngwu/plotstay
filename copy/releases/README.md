# 文案发布与回退记录

已发布批次：[2026-10-19 拉斯世界文案](2026-10-19-travel-copy.md)。

每次实际应用与发布后新增 `YYYY-MM-DD-主题.md`，记录：

- 涉及文案编号、语言和审定依据。
- 文案稿 Git 提交与应用代码提交；尚未提交时如实注明。
- 代码或数据库的实现位置，以及数据库发布前后实体、版本与发布 ID。
- 构建／发布时间、验证结果及未验证范围。
- 代码回退与重新部署步骤，或数据库历史版本恢复步骤。

文案稿由 Git 保存历史，不复制多份 final/v2 作为版本机制。数据库文案通过现有版本恢复功能回退；恢复 Markdown 或代码不会自动恢复数据库。禁止通过重跑 seed 或恢复整个数据库撤销文案修改，已有凭条与业务历史保持原快照。
