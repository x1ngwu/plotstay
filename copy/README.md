## 条目格式

短文字可用表格，长文字使用以下小节。稳定编号用于文案追踪，不擅自替换程序已有键。

```markdown
## home.hero.title

- 页面位置：首页首屏主标题
- 英文：待录入
- 中文：待录入
- 英文审定状态：待确认
- 中文审定状态：待确认
- 落地状态：未应用
- 实现位置：待核对代码键，或数据库实体与字段
- 决策来源：相关讨论与用户确认原文的定位
- 备注：适用范围、占位符或长度约束
```

审定状态按语言分别标记为「草拟／待确认／已确认」；落地状态为「未应用／已应用／已上线」。已应用表示实现已修改但尚未完成线上验证，已上线须关联发布记录。缺译直接注明，不自行把翻译标为已确认。人物或原则按决策条目记录，不强制制造界面键。

## 修改与版本

每个文件保留当前稿，历史通过 Git 差异与提交查看。修改时保留稳定编号并补充确认依据；文案提交尽量与无关功能修改分开。提交与推送遵循用户授权，不因建立目录自动执行。

本目录是审稿与交接入口。网站实际读取现有代码与数据库；文案文件本身不直接驱动页面。应用前核对当前生效值和目标字段，应用后同步落地状态与版本。数据库文案沿用现有保存、审核、发布及历史恢复机制，不重跑 seed，不重置数据。

只修改文档无需构建或重启服务。实际代码修改与部署遵循 [项目操作手册](../docs/operations.md)，数据库文案发布按既有版本机制验证，并写入发布记录。
