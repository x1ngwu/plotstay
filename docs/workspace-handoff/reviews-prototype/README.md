## 建议验收路径

1. 我的评价：查看三张互动卡片，选择／搜索角色，再切到收到的评价。角色聚焦沿用；点“全部角色”恢复。世界、类型、状态、关键词、排序和分页都实际作用于完整合成数据集，每页 3 条、各列表 7 条。
2. 我的评价第二条：进入编辑，分别输入中英文、展开补充信息、收起再展开，检查值仍保留。暂存 B 后展开版本区看 P/A/B；再次提交会询问是否替换 A。页尾“演示场景”内可模拟 A 获批，B 与本地输入保留。
3. 编辑后返回列表或浏览器后退：取消离开后输入仍在；放弃后恢复原列表范围、排序、页码、滚动。界面语言与正文语言页签彼此独立，不自动改变源语言。
4. 收到的评价第三条：阅读原提供者历史，没有编辑、保存或提交表单。新写评价先选条目、再确认角色；选择灯塔与林舟继续原记录，选择织补工坊与米拉开始新内容。
5. 在页尾“演示场景”中查看加载、读取失败、无记录、无权、暂不可用、保存失败、冲突、没有角色和长正文。选择冲突后尝试暂存，再比较并保留本地输入；文字仍是未保存状态。保存失败不是成功通知。

预览中的保存、提交、审核获批与冲突均为内存模拟，刷新重置。没有模拟账号切换来假称跨账号权限已通过。侧栏沿用实际工作台入口及手机菜单；角色、概览和管理等范围外入口只说明目的地，避免误入正式页面。

## 与参考图的对应和纠偏

- 图 01／02 的背景、角色、评价正文、嵌套回复、状态与操作顺序保留。取消右侧设计说明，不做铃铛、红点和未读数。当前预览账号为普通用户，管理审核入口按其能力不展示。
- 沿用 `4383ffe` 工作台样式快照和同一侧栏结构；评价样式限定 `.ws-reviews`。暖白、深绿主要操作和浅绿选中态，不复制灰度画布。不新增图片／上传，无图不留占位大框。
- 图 03／04 改为默认完整阅读、同详情进入编辑。普通长度的评价与回复在编辑态仍完整展开；只有长文可以折叠参考，展开后没有固定高度的内部滚动框。桌面编辑主区与评分／补充信息或回复状态分栏，手机改成单列；点击编辑直接定位写作区。纯阅读和只读态不显示保存按钮。
- 状态区区分 P 已公开、A 待审、B 未提交；版本区可分别阅读全文。只读原提供者显示原署名和失去写资格的原因，关联上下文受限的样例只展示允许的本人内容。
- 回复没有标题、评分、标签。评价保留标题／正文／总体评分／来自／旅程说明／关键词／实际分项评分；服务和活动只用 accuracy、communication、value，住宿另外有 cleanliness、checkIn、location。无评分不显示 0。
- 标题 200、评价正文 20000、回复正文 10000、来自／旅程说明 200、关键词最多 12 个且各 80，依据现有 Zod，长度按当前 JS 字符串契约。没有套用角色笔记的 2000 码点限制。单语言草稿可以保存，公开前要求双语；源语言仅在语言设置显式变更。
- 手机常显角色、搜索和排序，低频筛选可展开；长英文自然换行。沿用现有菜单行为，在文字放大时让品牌与菜单自然换行，避免绝对定位重叠。没有新横向总导航。
- 合成身份、日期、评分和文本独立于参考图。同一条目当前提供者保持一致；只读旧提供者身份另行保留。列表摘要优先公开评价 P，回复只显示当前观察者可读的合成版本。
