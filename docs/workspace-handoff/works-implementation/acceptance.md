# 阶段 B 隔离验收

本记录对照交接包 04。不是线上验收；不代表 G02/G04 已通过。环境：PostgreSQL 18 独立 tmpfs 容器 `plotstay-works-b-20261015`，仅绑定 `127.0.0.1:55439`；每个用例使用独立随机 schema。所有命令设置 `DOTENV_CONFIG_PATH=/dev/null` 和明确测试 `DATABASE_URL`。没有读取现用 .env 来 seed，没有连接现用数据库。

浏览器使用 Chromium、真实 Fastify API、临时端口及 `/tmp/plotstay-works-b-*` 的独立 Astro 构建。主矩阵账号是没有任何 `world_members` 权限的普通作者。初始 72 件作品、3 个世界、4 个角色、三类内容；通过实际领域命令持久化。网络失败/延迟用浏览器路由控制传输，未伪造业务成功数据。物理手机、软键盘、公网 Basic Auth 登录、部署后的环境未测。
