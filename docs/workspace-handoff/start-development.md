用户已认可草图的整体结构和交互，请直接推进实现，不再重复确认这些方向。
先完成“新版入口→作品列表→住宿编辑→保存并预览”的可操作检查点，
必要验证通过后部署供用户体验；随后继续第一阶段的角色、评价回复、
活动／服务编辑和管理工作区，不把住宿检查点当作全部交付。

   新版独立入口，建议 /{locale}/workspace。提供后台内双向切换，

3. 补全返回按钮和可点击面包屑，保留世界、语言、筛选、页码与返回位置；

4. 技术按已评估建议：Astro + TypeScript + 现有 schema 表单 + 受保护的真实
   页面预览，私有环境增加栏目定位。采用保存并预览，不引入自动保存、
   自由页面搭建或整套 CMS 迁移。草图只表达设计，不能当成生产代码直接接上。

   这是实施建议，先交可体验页面，不把草图配色当作最终定稿，也不改前台。
6. 按任务卡完成 BUG-001、BUG-002、BUG-004、FEATURE-002，复用 FEATURE-001；
   BUG-003 只处理后台范围，前台部分仍保留待办，不能宣称整项关闭。
   新旧表单读写需保持完整字段、双语项目身份及顺序、历史署名与版本。
7. WS-08～WS-13、世界创建／入驻等第二阶段实现暂不启动。
   D01～D03 及邀请细则待确认，不用它们阻塞第一阶段。
   不进入阶段 6 正式内容填充，不新增公开注册、角色主页或多轮讨论界面。

   测试写入隔离环境，不改写现用库的历史或用试验内容覆盖原数据。
9. 按任务风险完成 domain/API/浏览器验证、前台回归和新旧兼容检查。
   相关验证通过后按 operations 构建并更新开发域名，沿用已有部署授权，
   保持 Basic Auth、noindex、no-store、SITE_INDEXABLE=false 和 robots 禁止抓取。
   多人协作时由集成负责人串行迁移、构建和部署。

待人工体验清单。技术验证不代替用户验收；不要自行退役旧版或进入下一阶段。
