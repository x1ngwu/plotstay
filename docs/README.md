# Plotstay 文档

Plotstay 首期是围绕《战锤 40,000》Lathe Worlds（拉斯世界）的虚构旅行网页游戏，先完成中英双语的内容浏览和模拟预订。采用 digi-tech Lime 风格，以 dummy data 起步。**基础架构已确认：Astro 按需渲染、独立 Node.js / TypeScript API、PostgreSQL、后台翻译任务。** 内容需要审核与版本历史；翻译服务和密钥稍后配置。

基础方案已提交推送，阶段 1、2 已完成功能验收，阶段 2 实现已提交为 `f03cbef`。阶段 2.5「多语言 URL 与 SEO 规范修复」已完成并验收；阶段 3 的旅行平台式首页及 Q1–Q3 已确认：独立 Services、保存行程意向、现有账号登录管理。S3-00–S3-05 已完成开发及本地验收，桌面 / 手机运行预览、73 条全量遍历与服务管理流程均通过。方案状态以以下文档为准。

新 session 必须先阅读[开发顺序、进度与交接](development-status.md)、[视觉校准记录](phase-3-visual-alignment.md)及相关方案，核对当前工作区。阶段 3 功能和布局已获确认，中英文案已审定发布，当前视觉版本获用户认可并授权提交；后续细节按反馈迭代，不要自动进入阶段 4。美术基准为原版 `digi-tech-lime-desktop`，不使用 Colony 的视觉；发现栏目尺寸与间距依据用户提供的 Airbnb 参考包。
